# ATMAN-LATTICE — начать здесь

## Что можно использовать

Для изучения, локального запуска и проверки контрактов доступна исследовательская модель v1.19. Точный исходный коммит: `e62c279b9148a7ae9dd1a4654f6ddeea6add4a3f`. Команды воспроизведения — в [README](README.md). Это не заявление о готовности к промышленному внедрению.

Основные материалы: [model](model/), [schemas](schemas/), [инварианты](INVARIANTS.md), [полное описание протоколов](README.previous.md).

## Что ещё исследуется

Полный ATMAN и отдельный модуль полномочий — не одно и то же. Эксперименты CaPU × ATMAN используют только закреплённый модуль полномочий; их результаты нельзя переносить на весь стек. Промышленная защита ключей, транспорт, устойчивость хранилища и происхождение внешних данных остаются отдельными задачами.

## Как читать результаты

Открой [RESEARCH_INDEX.md](RESEARCH_INDEX.md): источник → точный коммит → свидетельства → ограничения. Полный машинный статус — [PROJECT_STATUS.json](PROJECT_STATUS.json). Сохранённый PASS относится к своему запуску, а не к любой последующей версии.

## Как продолжать без потери истории

Один вопрос — одна рабочая ветка. Новые результаты оформляй по [шаблону](EXPERIMENT_RECORD_TEMPLATE.md) и [общим правилам](REPOSITORY_GUIDE.md). Сохраняй отрицательные результаты. Сначала проверка и ревью выбранного изменения, затем отдельное решение о включении в основной код. Исторические ветки не удаляются автоматически.
