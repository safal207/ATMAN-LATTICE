## Хочу использовать

На main уже есть исполняемый исследовательский runtime v1.19. Установи зависимости в виртуальное окружение и запусти команды из README. Для первой задачи выбери один протокол, а не весь набор механизмов одновременно. Воспроизводимость reference не равна промышленной готовности.

## Хочу исследовать

Начни с INVARIANTS.md и протокола интересующего уровня. Для восстановления — v1.19; для наблюдения за изменениями — v1.18. Сигнал ухудшения не даёт права автоматически менять систему.

## Хочу понять связь с CaPU

В лабораториях CaPU используется только закреплённый model/authority.py. Полный ATMAN туда не подключён. Исходники, результаты и границы нужно смотреть в конкретных draft PR #103/#104 репозитория CaPU. Их публикация или успешные тесты не заменяют ревью кода.

## Что сохраняется

Старый README сохранён полностью. Код, схемы, протоколы, ветки и история не перемещены и не удалены. Новая навигация отличает reference, активное исследование, сохранённую историю и отдельную промышленную готовность.

Каждая новая работа должна оставлять точный коммит, вопрос, контроль, команды, результат, ограничения и статус ревью. Не превращаем один небольшой фикс в новую исследовательскую ветку без необходимости.
