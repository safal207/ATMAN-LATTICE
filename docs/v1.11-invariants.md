# ATMAN-LATTICE v1.11 — Multi-Hypothesis / Correlated Evidence Invariants

v1.11 extends the binary Bayesian loop into competing hypothesis distributions and makes evidence dependence an explicit, auditable part of the update context.

These are engineering invariants over declared probabilistic/dependency models. They do not prove that the declared hypotheses, likelihoods, or correlations are empirically correct.

## I-177 — Distribution Normalization

A multi-hypothesis state is valid only when it contains at least two unique canonical hypothesis references and their probability mass sums exactly to 10,000 basis points.

```text
sum_i P(H_i) = 1
```

## I-178 — Competition Is Preserved

Evidence redistributes mass across the complete declared hypothesis set. A positive observation for one explanation does not silently delete alternative explanations.

```text
Posterior = Normalize(Prior_i * Likelihood_i)
```

## I-179 — Exact Hypothesis Coverage

A multi-likelihood model must define likelihood for exactly the hypotheses present in the bound distribution.

```text
LikelihoodKeys = DistributionHypothesisKeys
```

No missing or extra hypothesis may enter through the likelihood surface.

## I-180 — Multi-Hypothesis Posterior Is Not Truth

```text
PosteriorDistribution != Truth
```

The posterior is a versioned belief state conditioned on explicit prior, likelihood, interpretation, and dependency assumptions.

## I-181 — Expected Information Gain Is Model-Conditional

Multi-hypothesis expected information gain is calculated over the declared distribution and likelihood model.

```text
EIG = H(Prior) - E[H(Posterior | Outcome)]
```

```text
ExpectedInformationGain != EmpiricalValidity
```

## I-182 — Dependency Semantics Must Be Precommitted

`INDEPENDENT`, `CONDITIONAL`, or `DUPLICATE` classification must be registered before verification completion.

```text
ObserveResult -> ChooseDependencyMode    forbidden
```

## I-183 — Same Source Is Not Two Evidence Units

```text
SameSourceEvent != IndependentEvidenceTwice
```

Different derivations, agents, summaries, or transport paths do not make one underlying source event independent evidence.

## I-184 — Derivation Is Not Independence

```text
DifferentDerivationHash != IndependentSource
```

A transformed or repeated representation of an existing observation retains source provenance.

## I-185 — Duplicate Evidence Does Not Advance Knowledge

Evidence explicitly declared `DUPLICATE` produces a duplicate receipt but no posterior distribution transition.

```text
DuplicateEvidence -> PreserveHistory
DuplicateEvidence -/> PosteriorAdvance
```

## I-186 — Duplicate Must Preserve Source Identity

A duplicate declaration must point to exactly one accepted parent evidence receipt and preserve its exact `source_event_hash`.

## I-187 — Conditional Evidence Requires Exact Parent Context

`CONDITIONAL` evidence may update a posterior only when its likelihood model binds the exact canonical parent evidence hash set declared by the dependency receipt.

```text
ConditionalLikelihood.parents = Dependency.parents
```

## I-188 — Independent Evidence Requires Unconditional Likelihood

An `INDEPENDENT` evidence declaration cannot use a likelihood model conditioned on earlier evidence.

```text
Independent -> conditioning_evidence_hashes = []
```

## I-189 — Accepted Source Uniqueness Is Atomic

The runtime stores accepted evidence with a database uniqueness constraint on `source_event_hash` and performs apply under `BEGIN IMMEDIATE`.

Two racing processes cannot both count the same source event as fresh accepted evidence in the same SQLite deployment boundary.

## I-190 — Distribution Generation Is Monotonic

A non-duplicate accepted evidence update advances the shared distribution exactly one generation.

```text
PosteriorGeneration = PriorGeneration + 1
```

## I-191 — Multi-Likelihood Rebase Is Not Re-Estimation

After a shared distribution advances, cohort likelihood models may be freshness-rebound to the posterior while preserving their conditional likelihood values.

```text
Rebase != Reestimate
```

Changing sensitivity or outcome likelihood requires an explicit new model rather than a freshness rebase.

## I-192 — Dependency Authority Is Separate

```text
ModelAuthority != DependencyAuthority != UpdateAuthority
```

The actor allowed to define competing hypotheses/likelihoods does not automatically gain authority to classify evidence as independent, conditional, or duplicate; neither role automatically gains posterior-update authority.

## I-193 — Stale Correlation Context Cannot Commit

A runtime preview binds current distribution, model, dependency declaration, evidence rule, completion, parent evidence, source-count state, and cohort model hashes.

If any of these change before apply:

```text
OldPreview != CurrentUpdateAuthority
```

## I-194 — Dependency Graph Is Evidence About the Model, Not Proof of Reality

A valid dependency declaration proves which dependency assumptions were committed and used by the runtime.

It does not by itself prove that the real-world signals are truly independent or correlated.

```text
ValidDependencyReceipt != ProvenPhysicalCausality
```
