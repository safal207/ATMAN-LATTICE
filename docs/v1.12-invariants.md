# ATMAN-LATTICE v1.12 Invariants

## I-195 — Calibration Requires Frozen Assumptions

A probability or likelihood may be calibrated only if its exact model state was committed before the outcome used to score it.

```text
PosthocModel != HistoricalForecast
```

## I-196 — Resolution Is Not Ontological Truth

A `ResolvedOutcomeReceipt` is an authoritative calibration target under the current resolution process, not proof of metaphysical or physical truth.

```text
Resolution != OntologicalTruth
```

## I-197 — Confidence Does Not Imply Calibration

High probability does not make a forecast historically reliable.

```text
Confidence != Calibration
```

## I-198 — Forecast Calibration Binds the Exact Distribution

The score must bind the exact frozen distribution hash and probability vector that existed before resolution.

## I-199 — Likelihood Calibration Binds Exact Evidence

Likelihood calibration must bind the exact frozen likelihood hash, dependency hash, provenance source, and accepted evidence receipt.

## I-200 — Inconclusive Is Not Forced Into a Binary Outcome

`INCONCLUSIVE` evidence is preserved but is not scored as positive or negative.

```text
INCONCLUSIVE != POSITIVE
INCONCLUSIVE != NEGATIVE
```

## I-201 — Calibration Target Precedes Verification Completion

The runtime must reject attempts to create a calibration target after the candidate's result is already known.

## I-202 — Resolution Follows Target Commitment

A resolution used for calibration cannot predate the frozen calibration target.

## I-203 — Resolution History Is Immutable in v1.12

Once a distribution/case has a registered resolved outcome, it cannot be silently replaced by a different outcome.

```text
Correction != SilentOverwrite
```

## I-204 — Calibration History Is Append-Only Evidence

Forecast and likelihood calibration receipts preserve historical scoring material. A later model does not rewrite an earlier score.

## I-205 — Calibration Signal Is Not Model Mutation Authority

A `MISCALIBRATION_SIGNAL` cannot directly modify priors, likelihoods, dependency declarations, A4 decisions, execution permissions, or trust roots.

```text
CalibrationSignal != RewriteAuthority
```

## I-206 — Dependency Learning Requires Repeated Resolved Samples

A statistical independence/dependence assessment must report insufficient evidence below its explicit minimum sample count.

## I-207 — No Dependency Signal Does Not Prove Independence

Failure to detect a dependence signal is weaker than proof that two real-world signals are independent.

```text
NoDependencySignal != ProvenIndependence
```

## I-208 — Dependency Signal Does Not Prove Causality

Empirical association can challenge an independence model without proving a causal mechanism.

```text
DependencySignal != ProvenCausality
```

## I-209 — Conditional Evidence Preserves Exact Parent Binding

Statistical samples for declared conditional evidence must preserve the declared parent evidence relationship.

## I-210 — Duplicate Evidence Is Not Relearned as Independent Evidence

Structurally duplicate evidence remains zero new Bayesian evidence units and is not promoted into an ordinary independence sample.

## I-211 — Calibration Roles Are Separate

```text
CALIBRATION_TARGET_KEEPER
!= CALIBRATION_RESOLVER
!= CALIBRATION_RECORDER
```

The authority to freeze assumptions, resolve outcomes, and score models is not interchangeable.

## I-212 — Brier Scoring Is Deterministic

The same frozen probability vector and resolved outcome must produce the same integer calibration score.

## I-213 — Family Aggregation Preserves Individual Receipts

A family-level calibration summary is a projection over immutable observations, not a replacement for those observations.

## I-214 — Report Thresholds Are Policy, Not Truth

Changing minimum sample counts or alert thresholds can change the diagnostic label without changing the underlying calibration receipts.

```text
DiagnosticPolicy != EvidenceHistory
```

## I-215 — Same Resolved Case Cannot Be Counted Twice for One Dependency Pair

The runtime pair history is unique by `(pair_key, resolution_hash)` inside the reference SQLite boundary.

## I-216 — Observer Error Must Remain Observable

A later model revision must not erase evidence that an earlier version was miscalibrated or used a challenged independence assumption.

```text
Learning != HistoryErasure
```
