# v1.9 Invariants — Information Gain / Active Verification

## I-146 — Expected Information Gain Is Not Truth

> A high expected information gain is a property of an explicit uncertainty/likelihood model, not a semantic verdict about the world.

```text
High EIG != PASS
Low EIG != FAIL
```

## I-147 — Selection Is Not Verification

> Selection allocates attention; it does not complete the selected check.

```text
SELECTED != VERIFIED
```

## I-148 — Model Inputs Must Be Explicit

> Prior probability and outcome likelihoods must be represented as versioned artifacts rather than ambient scheduler assumptions.

## I-149 — Hypothesis State Is Evidence-State Bound

> A hypothesis probability commits the exact evidence-state digest and generation from which it was derived.

## I-150 — Likelihood Is Exact-Hypothesis Bound

> A likelihood model for hypothesis generation H1 cannot be silently reused after the hypothesis changes to H2.

```text
Likelihood(H1) != Likelihood(H2)
```

## I-151 — Candidate/Likelihood Binding

> Information gain may be computed only when the likelihood model commits the exact candidate being ranked.

## I-152 — Identity Binding Survives Active Selection

> Candidate and hypothesis must refer to the same subject identity before information gain is computed.

## I-153 — Information Gain Is Entropy Reduction

> In the v1.9 binary reference model:

\[
EIG = H(prior)-E[H(posterior\mid outcome)] \ge 0.
\]

The receipt must preserve that arithmetic relation after quantization.

## I-154 — Cost and Information Remain Separate Evidence

> Expected information gain does not determine verification cost, and observed verification cost does not determine information value.

```text
Information != Cost
```

Ranking may combine them; provenance must preserve both inputs separately.

## I-155 — Active Ranking Uses Current Cost Evidence

> Information-per-cost ranking must use the current v1.8 estimator state, not caller-declared cost as accounting truth.

## I-156 — Unmodeled Does Not Mean Invalid

> Missing or stale uncertainty models preserve work as unresolved active-verification debt.

```text
UNMODELED != INVALID
UNMODELED != PRUNED
```

## I-157 — Low Expected Gain Does Not Erase Work

> A candidate below the current information threshold is deferred, not silently removed from history or verification debt.

## I-158 — Active State Is Use-Time Bound

> A preview may be finalized only while the current candidate, estimator, hypothesis, likelihood, and policy state still matches the preview state digest.

```text
OldKnowledgePreview != CurrentSelectionAuthority
```

## I-159 — Model Keeper Is Not Plan Keeper

> Authority to register uncertainty models does not automatically grant authority to finalize which verification work receives active-selection budget.

## I-160 — Active Verification Cannot Cross Into Truth Authority

> Neither model registration nor active-plan finalization may directly produce A3/A4 PASS, mutate verification completion, or authorize privileged execution.

```text
Model -> Expected information
Plan  -> Attention allocation
Verify -> Evidence verdict
A4    -> Coherence finalization
```

These are distinct authority and semantic layers.
