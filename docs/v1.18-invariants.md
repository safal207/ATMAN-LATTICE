# ATMAN-LATTICE v1.18 — Temporal / External Replication Invariants

v1.18 adds monitoring of a previously confirmed graph across fresh time windows and/or declared external sources. It does not grant automatic rollback or mutation authority.

## I-337 — One Confirmation Is Not Permanent Generalization

`OneConfirmation != PermanentGeneralization`

A v1.17 confirmation is evidence for one protected confirmation event, not an eternal guarantee.

## I-338 — Confirmed At t Is Not Confirmed At t+1

`Confirmed_t != Confirmed_t+1`

Later environments and later time windows require new evidence.

## I-339 — Internal Fresh Holdout Is Not External Replication

`InternalFreshHoldout != ExternalReplication`

External replication requires a distinct declared source.

## I-340 — Different Source Ref Is Not Proven Independence

`DifferentSourceRef != ProvenIndependence`

Source provenance prevents mislabeled reruns but does not prove institutional, causal, or statistical independence.

## I-341 — Replication Target Binds Exact Confirmed Revision

A replication target binds the exact v1.17 confirmed revision, candidate, graph, confirmation evaluation, review, and confirmation batch.

## I-342 — Replication Baseline Is Immutable

Historical confirmation metrics used as the replication baseline cannot be silently recomputed after later observations.

## I-343 — Replication Data Cannot Predate Confirmation

Replication collection begins no earlier than the baseline confirmation evaluation.

## I-344 — Temporal Replication Requires Explicit Gap

For temporal modes, `collected_from - confirmation_evaluated_at >= min_temporal_gap`.

## I-345 — Temporal Windows Advance Without Overlap

Later replication generations must begin after the prior generation's collection window ends.

## I-346 — Replication Generation Advances Exactly Once

`R_n -> R_(n+1)` with exact previous-batch lineage.

## I-347 — New Timestamp Label Is Not New Evidence

Renaming or rebucketing the same observations cannot create another replication epoch.

## I-348 — External Replication Uses Distinct Confirmation Source

`EXTERNAL` and `TEMPORAL_EXTERNAL` reject the original v1.17 confirmation source ref.

## I-349 — Search Evidence Cannot Be Reused As Replication

Replication must be sample-, resolution-, and evidence-provenance-disjoint from search/discovery history.

## I-350 — Confirmation Evidence Cannot Be Reused As Replication

The protected v1.17 confirmation set cannot later be relabeled as replication evidence.

## I-351 — Prior Replication Evidence Cannot Be Recounted

Later replication generations cannot reuse sample, resolution, or evidence provenance from earlier replication generations.

## I-352 — New Sample Hash Is Not Sufficient Freshness

`NewSampleHash != FreshProvenance`

Reusing an old resolution or evidence source remains reuse.

## I-353 — Replication Does Not Retrain

`Replication != Retraining`

Replication scoring uses the original frozen candidate selection/training samples.

## I-354 — Replication Data Is Score-Only

Replication samples cannot alter the predictor before their replication receipt is issued.

## I-355 — Structural Drift Is Separate From Performance Drift

A structure can lose comparative advantage even when absolute Brier degradation remains tolerable, or vice versa.

## I-356 — Drift Kind Is Explicit

Complete replication evaluates one of `NONE`, `STRUCTURAL`, `PERFORMANCE`, or `BOTH`.

## I-357 — Drift Signal Is Not Model Falsehood

`DriftSignal != ModelFalsehood`

A failed monitoring policy is not an ontological proof that the model is impossible.

## I-358 — Drift Signal Is Not Rollback Authority

`DriftSignal != RollbackAuthority`

v1.18 cannot mutate or revert the graph.

## I-359 — Drift Signal Does Not Explain Drift Cause

`DriftSignal != DriftCause`

Observed deterioration does not identify mechanism or causality by itself.

## I-360 — Replication Evaluator Is Independent

The replication evaluator cannot be the replication batch keeper, original candidate proposer, or original confirmation evaluator.

## I-361 — Replication Reviewer Is Independent

The replication reviewer cannot be the replication batch keeper or replication evaluator.

## I-362 — Persistent Drift Requires Multiple Acknowledged Epochs

`PERSISTENT_DRIFT_SIGNAL` requires the configured number of consecutive acknowledged drift evaluations.

## I-363 — Disputed Observations Do Not Enter Series Snapshot

A replication series snapshot contains only `ACKNOWLEDGE`d observations.

## I-364 — Historical Replication Target Is Not Current Model Status

If the current graph changes, an older target remains auditable history but cannot represent current replication status.

## I-365 — Current Graph Must Match Confirmed Target At Evaluation

Runtime evaluation rejects a replication target whose confirmed graph is no longer current.

## I-366 — Replication Is Not Causality Proof

`REPLICATED != ProvenCausality`

The graph edge remains `STATISTICAL_CONDITIONING`.

## I-367 — Replication Is Not Universal Validity

`REPLICATED != UniversalValidity`

One external or temporal environment does not establish all environments.

## I-368 — Replication State Is Append-Only Evidence

Policies, targets, batches, evaluations, reviews, and snapshots are preserved as durable historical receipts.

## I-369 — Monitoring Authority Is Not Mutation Authority

No `ATMAN-REPLICATE/1.18` role can change the current dependency graph.

## I-370 — Replication Cannot Bypass v1.17 Confirmation

A replication target can only originate from an applied, independently reviewed `CONFIRMED` v1.17 revision.
