# ATMAN-LATTICE v1.4 — Transition Geometry

v1.4 introduces a **discrete engineering analogue** of torsion and curvature for state-transition systems.

This is not a claim about physical torsion fields or a literal identification with differential geometry. The goal is narrower: make **path dependence** and **closed-loop drift** explicit, hash-bound, and testable in agent workflows.

## 1. Why state validity is not enough

Suppose two transitions `A` and `B` are each locally valid.

```text
        A
   X -------> XA
   |           |
 B |           | B
   v           v
  XB -------> ?
        A
```

Local validity does not imply that order is irrelevant:

\[
Valid(A) \land Valid(B)
\not\Rightarrow
B(A(X)) \simeq A(B(X)).
\]

The difference between the two composed paths is the v1.4 **transition torsion** signal.

## 2. Transition endpoints

A `TransitionEndpoint` binds a committed `IdentityReceipt` to three additional execution-relevant projections:

```text
identity_ref
payload_digest
context_digest
authority_digest
effect_digest

lineage_root_hash
branch_ref
generation
receipt_hash
```

The first group forms the v1.4 **semantic vector**. The second group forms the **history vector**.

This separation is deliberate. Two paths may produce the same semantic state while still belonging to different causal histories.

## 3. Transition operators

A `TransitionOperator` commits to:

```text
operator_ref
action_digest
operator_hash
```

The torsion receipt binds `A` and `B` in exact order. A receipt for one pair/order cannot be silently reused for another.

## 4. Discrete torsion

The model uses the engineering analogue:

\[
\tau_X(A,B)
=
\Delta(B\circ A(X),\;A\circ B(X)).
\]

`Delta` is represented as explicit mismatch dimensions rather than one opaque scalar.

### Statuses

```text
CLOSED
```

The two orderings produce the exact same endpoint.

```text
SEMANTICALLY_CLOSED_HISTORY_DIVERGENT
```

The semantic vectors agree, but branch/lineage/generation/receipt history differs.

```text
TORSION_DETECTED
```

At least one semantic dimension differs: identity, payload, context, authority, or effects.

This distinction prevents an important collapse:

```text
same observable result != same causal path
```

## 5. Closed-loop curvature

For an operator loop `L` that is intended to return to the same semantic point, v1.4 measures:

\[
\kappa_X(L)=\Delta(X,L(X)).
\]

Again, this is a discrete engineering diagnostic, not a literal tensor definition.

### Statuses

```text
FLAT_LOOP
```

The returned endpoint is exactly the origin endpoint.

```text
SEMANTICALLY_CLOSED_WITH_HOLONOMY
```

The semantic vector returned, but historical coordinates advanced or diverged.

```text
CURVATURE_DETECTED
```

The loop changed at least one semantic dimension.

This allows the model to say:

> The system returned to the same operational state, but it did not erase the fact that a journey occurred.

## 6. Relationship to v1.3 multiverse semantics

Torsion and incursion are not synonyms.

```text
TORSION_DETECTED
      |
      | order matters
      v
compatibility / policy evaluation
      |
      +-- compatible -> preserve both paths if useful
      |
      +-- incompatible -> IncursionReceipt / reconciliation
```

Therefore:

\[
Torsion \neq Invalidity.
\]

A path-dependent system may be perfectly legitimate. The important requirement is that the dependence is not hidden.

## 7. AI-agent examples

Order-sensitive pairs include:

```text
read evidence -> update plan
update plan   -> read evidence
```

```text
verify -> rotate policy
rotate policy -> verify
```

```text
restore -> merge
merge -> restore
```

```text
summarize memory -> persist
persist -> summarize memory
```

Each individual operation may be valid while the compositions differ.

## 8. Evidence model

`TransitionTorsionReceipt` binds:

```text
origin endpoint
operator A
operator B
A-then-B endpoint
B-then-A endpoint
semantic deltas
history deltas
status
measurement time
```

`TransitionCurvatureReceipt` binds:

```text
origin endpoint
returned endpoint
ordered loop operators
semantic drift
history holonomy
status
measurement time
```

The verifier recomputes expected evidence from the actual endpoints and operators. A self-consistent receipt for a different path is rejected.

## 9. Boundary of v1.4

v1.4 is an executable semantic layer. It does **not** yet add new `ATMAN-RUNTIME` wire operations or automatically block execution when torsion/curvature is detected.

A future runtime integration can use these receipts as inputs to A3/A4, incursion classification, planning, scheduling, or reconciliation policy.

The central rule is:

> **A transition system must not infer path independence merely because every individual step passed validation.**
