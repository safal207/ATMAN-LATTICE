# ATMAN-LATTICE Invariants v1.4 — Transition Geometry

These invariants define the executable transition-geometry layer introduced in v1.4.

They are discrete engineering contracts inspired by geometric ideas. They are not claims about physical torsion fields, spacetime, or metaphysical reality.

## I-86 — Local Validity Does Not Imply Commutativity

> Two individually valid transitions are not assumed to commute.

For transitions `A` and `B`:

\[
Valid(A) \land Valid(B)
\not\Rightarrow
B(A(X)) \simeq A(B(X)).
\]

Order dependence must be measured rather than assumed away.

## I-87 — Exact Operator-Order Binding

> A torsion claim must bind the exact transition operators in exact order.

A receipt measured for `(A,B)` cannot validate `(A,C)`, `(B,A)`, or another action digest without explicit recomputation.

## I-88 — Semantic Closure Is Distinct From Historical Closure

> Equal semantic outcomes do not imply equal causal histories.

If semantic vectors match but lineage root, branch, generation, or receipt hash differs, the correct classification is:

```text
SEMANTICALLY_CLOSED_HISTORY_DIVERGENT
```

not `CLOSED`.

## I-89 — Torsion Must Be Explicit Before Reconciliation

> Order-dependent semantic divergence must be exposed before two path results are treated as interchangeable.

A detected torsion signal may trigger compatibility or reconciliation policy, but it must not be silently normalized away.

## I-90 — Torsion Is Diagnostic, Not Automatic Rejection

> Path dependence does not by itself make either path invalid.

\[
Torsion \neq Invalidity.
\]

Whether a torsion-bearing pair may coexist is a separate policy/compatibility question.

## I-91 — Closed-Loop Semantic Return Does Not Erase History

> A loop may return to the same semantic state while historical coordinates advance.

This is represented as:

```text
SEMANTICALLY_CLOSED_WITH_HOLONOMY
```

The system must not rewrite the journey out of lineage merely because the operational state returned.

## I-92 — Closed-Loop Drift Must Be Measurable

> If an intended return loop changes identity, payload, context, authority, or effects, the semantic drift must be explicit.

The classification is:

```text
CURVATURE_DETECTED
```

with exact drift dimensions.

## I-93 — Geometry Receipts Bind Actual Evidence

> A self-consistent geometry receipt for another path is not valid evidence for the current path.

Verification must compare the receipt with the actual origin, endpoints, operators, and operator ordering.

Rehashing or replaying a different receipt is insufficient.

## I-94 — History Holonomy Is Separate Evidence

> Historical divergence is preserved independently from semantic divergence.

The v1.4 history vector is:

```text
lineage_root_hash
branch_ref
generation
receipt_hash
```

This allows a system to distinguish "same result" from "same journey".

## I-95 — Transition Geometry Does Not Grant Authority

> Measuring torsion or curvature does not itself authorize, reject, merge, prune, or rewrite a branch.

Geometry receipts are evidence inputs. Runtime authority, incursion policy, reconciliation, and governance remain separately controlled by their existing contracts.

## Executable counterexamples

The v1.4 suite demonstrates that:

1. identical `A->B` and `B->A` endpoints classify as `CLOSED`;
2. semantically identical results on different histories are not collapsed into exact closure;
3. different payload outcomes produce `TORSION_DETECTED`;
4. a valid torsion receipt for a different path fails exact evidence binding;
5. an exact closed loop is `FLAT_LOOP`;
6. semantic return with a different lineage records history holonomy;
7. changed execution context after a loop produces `CURVATURE_DETECTED`;
8. a curvature receipt cannot be reused for a different loop operator set.

## Core formulas

Discrete torsion diagnostic:

\[
\tau_X(A,B)=\Delta(B\circ A(X),A\circ B(X)).
\]

Discrete closed-loop drift diagnostic:

\[
\kappa_X(L)=\Delta(X,L(X)).
\]

Here `Delta` is not reduced to one number. It is represented by explicit semantic and historical mismatch dimensions.
