# ATMAN-LATTICE v1.0 Runtime Invariants

## I-53 — Privileged Execution Boundary

A governed observer primitive executed by the ATMAN Runtime must run inside the runtime worker process, not in the caller process.

## I-54 — Server-Owned Trust Configuration

Trusted issuer roots, the current authority policy generation, and the verification clock are runtime-owned inputs. Request fields cannot replace them.

## I-55 — Exact Runtime Action Reconstruction

The runtime must reconstruct the canonical operation action from the decoded runtime inputs before authority verification. A caller-supplied description of the intended action is not sufficient authorization evidence.

## I-56 — Client Mutation Isolation

Mutating or monkeypatching the caller process must not mutate the worker process implementation used to execute a privileged observer operation.

## I-57 — Reject Before Privileged Execution

If the authority grant/proof fails signer, role, scope, action, policy-generation, trust-root, or validity-window verification, the privileged primitive must not execute and no successful ObserverReceipt may be returned.

## I-58 — Boundary Claim Must Match Deployment

The runtime may be described as non-bypassable only relative to a deployment in which callers do not control the worker process, worker package, server trust configuration, or equivalent privileged execution surface.

A same-process library boundary or an attacker-controlled host does not satisfy this invariant.

## Compact form

```text
RuntimeAuthority =
    ServerTrust
  × ExactAction
  × Signer
  × Role
  × Scope
  × PolicyGeneration
  × Time
  × ProcessBoundary
```

and:

```text
CallerMutation != RuntimeMutation
CallerClaim    != ServerAuthority
RejectedProof -> NoPrivilegedExecution
```
