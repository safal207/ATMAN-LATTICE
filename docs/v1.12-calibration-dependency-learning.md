# v1.12 — Calibration / Dependency Learning

v1.12 audits the observer itself.

Earlier layers let ATMAN-LATTICE represent competing hypotheses, precommit evidence semantics, track provenance, and avoid double-counting duplicate sources. v1.12 asks a different question:

> When later outcomes are resolved, did the earlier probabilities and dependence assumptions behave the way the model claimed they would?

The new process plane is:

```text
ATMAN-CALIBRATION/1.12
```

It is diagnostic and append-only. A calibration signal cannot directly rewrite priors, likelihoods, dependency declarations, A4 verdicts, execution permissions, or trust policy.

## Frozen assumptions before outcome

Calibration is only meaningful if the model being scored existed before the result was known.

`CalibrationTargetReceipt` freezes the exact:

```text
distribution hash + probability vector
likelihood model hash + likelihood vector
dependency hash + mode + provenance parents
candidate / subject identity
calibration family
commit time
```

The runtime refuses to register a target after verification completion or after a resolution already exists.

```text
Calibration requires frozen pre-outcome assumptions.
```

This prevents a model from being rewritten after a miss and then scored as if the rewritten model had made the original prediction.

## Resolution is a calibration reference, not ontological truth

`ResolvedOutcomeReceipt` binds an externally resolved hypothesis label to a distribution/case and a provenance digest for the resolution source.

```text
Resolution != Ontological Truth
```

A resolution is the current authoritative target used for audit. Its quality still depends on the resolver, source, policy, and operational process outside this reference model.

The reference runtime makes a resolution immutable once registered. Corrections therefore require a later explicit protocol rather than silent history replacement.

## Forecast calibration

For a categorical forecast over mutually exclusive hypotheses, v1.12 uses the Brier score:

```text
Brier = sum_i (p_i - y_i)^2
```

where `y_i=1` for the resolved hypothesis and `0` otherwise.

The receipt stores an integer parts-per-million representation.

Examples for a binary distribution:

```text
predict A=100%, A resolves -> 0 ppm
predict A=50%,  A resolves -> 500000 ppm
predict A=0%,   A resolves -> 2000000 ppm
```

A confident wrong forecast is therefore penalized more than an uncertain wrong forecast.

```text
Confidence != Calibration
```

## Likelihood calibration

The multi-hypothesis likelihood model claims, for each hypothesis:

```text
P(positive evidence | H_i)
```

Once the case resolves to `H_k`, v1.12 compares the model's frozen `P(+|H_k)` against the evidence outcome actually observed.

For conclusive positive/negative evidence, the runtime records a binary Brier score.

`INCONCLUSIVE` evidence is preserved but not coerced into a positive or negative calibration sample.

```text
Inconclusive != Negative
Inconclusive != Positive
```

## Family-level calibration snapshots

Calibration observations can share a stable `calibration_family_ref`.

The family snapshot reports:

```text
forecast sample count
mean categorical Brier score
likelihood scored sample count
mean likelihood Brier score
mean predicted positive rate
observed positive rate
marginal calibration gap
```

The reference classification is:

```text
INSUFFICIENT_SAMPLES
NO_MARGINAL_MISCALIBRATION_SIGNAL
MISCALIBRATION_SIGNAL
```

The threshold and minimum sample count are explicit report policy inputs.

`NO_MARGINAL_MISCALIBRATION_SIGNAL` is deliberately weaker than a claim that the model is perfectly calibrated. Marginal rates can look correct while conditional or subgroup calibration is still wrong.

## Dependency learning

v1.11 records the declared evidence relation:

```text
INDEPENDENT
CONDITIONAL
DUPLICATE
```

v1.12 can accumulate repeated resolved pair samples for the same signal families and resolved hypothesis.

For two binary evidence signals `L` and `R`, the reference statistic measures the signed difference between:

```text
observed P(L+ and R+)
```

and the joint rate expected under empirical independence:

```text
P(L+) * P(R+)
```

The difference is stored in basis points as `independence_gap_bps`.

For declared independent signals:

```text
large empirical gap -> INDEPENDENCE_CHALLENGED
small empirical gap -> NO_DEPENDENCY_SIGNAL
```

For declared conditional signals:

```text
large empirical gap -> CONDITIONAL_DEPENDENCY_SUPPORTED
small empirical gap -> CONDITIONAL_DEPENDENCY_NOT_OBSERVED
```

These are audit signals, not causal proofs.

```text
NoDependencySignal != ProvenIndependence
DependencySignal != ProvenCausality
```

A dependency graph remains a model of evidence relationships. Real-world causal independence cannot be established from a hash, a declaration, or one correlation statistic alone.

## Why duplicates are not statistically relearned

`DUPLICATE` already has a structural provenance rule in v1.11: the duplicate must preserve the exact `source_event_hash` of its accepted parent and cannot advance the posterior.

v1.12 therefore does not reinterpret duplicate evidence as an ordinary statistical pair. It remains a preserved observation with zero new Bayesian evidence units.

## Runtime separation

v1.12 introduces three roles:

```text
CALIBRATION_TARGET_KEEPER
CALIBRATION_RESOLVER
CALIBRATION_RECORDER
```

They are intentionally separate:

```text
FreezeModel != ResolveOutcome
ResolveOutcome != ScoreModel
ScoreModel != RewriteModel
```

The calibration plane may emit evidence that a model should be reviewed, but model mutation remains outside its authority.

## Durable state

The SQLite reference plane stores:

```text
calibration targets
resolved outcomes
forecast calibration receipts
likelihood calibration receipts
dependency pair samples
```

Targets and resolutions are immutable in the reference runtime, and observation rows are unique by frozen target/evidence or pair/case binding.

## Epistemic boundary

v1.12 proves things about the internal audit process:

- which probability vector was frozen before outcome;
- which resolution was used as the calibration target;
- which evidence and likelihood were scored;
- which repeated samples produced a dependency signal;
- which authority performed each mutation.

It does **not** prove that the resolver is infallible, that the declared hypothesis set contains the true explanation, or that empirical dependence establishes physical causality.

The purpose is narrower and useful:

> Make the observer's historical errors measurable without granting the observer permission to rewrite its own past predictions.
