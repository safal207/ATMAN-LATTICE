# ATMAN-LATTICE v1.13 Invariants

## I-217 — Calibration Signal Is Not Mutation Authority

A `MISCALIBRATION_SIGNAL` may justify a proposal but cannot directly change the current model.

```text
CalibrationSignal != RewriteAuthority
```

## I-218 — Proposal Is Not Mutation

A `ModelRevisionProposal` is an immutable candidate transition, not an applied state change.

```text
Proposal != Mutation
```

## I-219 — Revision Proposal Binds the Exact Base Model

The proposal must bind the exact current model hash, distribution hash, model generation, and calibration snapshot hash.

## I-220 — Revision Advances Exactly One Model Generation

A proposed and applied likelihood revision must advance:

```text
Model N -> Model N+1
```

without skipping or rewriting generations.

## I-221 — Hypothesis Set Is Stable During Numeric Likelihood Revision

v1.13 may change likelihood values but not silently change the hypothesis set represented by the bound distribution.

## I-222 — Conditioning Context Is Preserved During Numeric Revision

A numeric likelihood revision preserves the exact conditioning evidence hashes of the base model.

```text
LikelihoodValueRevision != DependencyRewrite
```

## I-223 — Counterfactual Replay Uses Historical Resolved Evidence

Replay must score the proposal on persisted, already resolved calibration observations rather than fabricated future outcomes.

## I-224 — Replay Preserves the Exact Case Set

The replay receipt binds the sorted unique hashes of every scored historical case used in its comparison.

## I-225 — Replay Improvement Is Measured, Not Asserted

`IMPROVED` requires strictly lower mean Brier score for the proposal on the bound case set.

## I-226 — Replay Improvement Does Not Imply Approval

```text
ReplayImprovement != Approval
```

A better historical fit does not automatically authorize model mutation.

## I-227 — Insufficient Replay Cannot Be Approved

`INSUFFICIENT_SCORABLE_CASES` cannot produce an `APPROVE` review.

## I-228 — No-Improvement Replay Cannot Be Approved

`NO_IMPROVEMENT` cannot produce an `APPROVE` review.

## I-229 — Reviewer Must Be Independent of Proposer

```text
proposer_ref != reviewer_ref
```

The actor proposing a model revision cannot issue the approving review for the same proposal.

## I-230 — Review Is Not Apply Authority

```text
Review != Apply
```

An approved review does not itself mutate runtime state.

## I-231 — Apply Requires Exact Proposal / Replay / Review Binding

Apply must bind the exact proposal hash, replay hash, and review hash that were independently persisted.

## I-232 — Apply Is Use-Time Bound to Current Model State

If the current model or distribution changed after proposal, apply must reject rather than force the stale revision.

```text
OldProposal != CurrentMutationAuthority
```

## I-233 — Apply Is Use-Time Bound to Current Calibration History

Before mutation, replay must still describe all currently persisted relevant calibration cases. New calibration observations invalidate the old replay/review path.

```text
OldReplay != CurrentRevisionAuthority
```

## I-234 — Old Model State Is Preserved

Successful apply updates the current model pointer but stores the exact old and new model JSON in append-only revision history.

```text
NewModel != RewrittenOldModel
```

## I-235 — Learning From Error Does Not Erase Error

Historical calibration targets, resolutions, calibration receipts, and the miscalibrated base model remain auditable after revision.

```text
LearningFromError != ErasingError
```

## I-236 — Revision Roles Are Separate

```text
MODEL_REVISION_PROPOSER
!= MODEL_REVISION_REPLAY_KEEPER
!= MODEL_REVISION_REVIEWER
!= MODEL_REVISION_APPLIER
```

Authority at one revision stage does not imply authority at the next stage.

## I-237 — Dependency Challenge Is Not Permission to Invent Conditioning Context

v1.13 does not automatically convert an `INDEPENDENCE_CHALLENGED` signal into a conditional likelihood model.

```text
DependencyChallenge != DependencyRewriteAuthority
```

## I-238 — Historical Improvement Is Not Future Truth

Counterfactual replay establishes fit on a bound historical sample set. It does not prove future calibration, causal correctness, or out-of-distribution performance.

```text
HistoricalFit != FutureTruth
```
